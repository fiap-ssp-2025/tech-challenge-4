# Solicitação do dataset VERBO (manual)

O VERBO (*Voice Emotion Recognition dataBase in Portuguese language*) **não é baixado automaticamente** neste repositório. Os autores pedem formulário + e-mail.

- Site: https://sites.google.com/view/verbodatabase/
- Formulário: https://drive.google.com/file/d/1X9zT9p2lF3m1dqjfJjnf0QXQ8GvRtzjm/view
- E-mail dos autores: `jrtorresneto@gmail.com` (também listado como `jrtorresneto@usp.br` no site)
- Paper: Torres Neto et al., 2018 — [DOI 10.3844/jcssp.2018.1420.1430](https://doi.org/10.3844/jcssp.2018.1420.1430)

## Passos

1. Baixar e preencher o formulário do Drive acima.
2. Enviar o formulário anexado ao e-mail abaixo (copiar/colar e ajustar os campos entre colchetes).
3. Quando o acesso chegar, colocar os áudios em `data/audio_ptbr/raw/verbo/` (git-ignored) e documentar no relatório; o núcleo do A3 fecha só com CORAA se o VERBO não chegar a tempo.
