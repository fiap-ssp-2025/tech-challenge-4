# Specs

Cada pasta `NNN-slug/` é uma feature (ou change) versionada.

## Conteúdo mínimo

| Arquivo | Papel |
|---------|-------|
| `spec.md` | What / why + critérios de aceite |
| `plan.md` | How — stack e arquitetura |
| `tasks.md` | Checklist executável |

Use os templates em `.specify/templates/`.

## Status sugeridos

`draft` → `ready` → `in-progress` → `done`
